Забирай данные о транзакциях из REST API банка https://api.bank.example.com/transactions каждые 30 секунд, фильтруй транзакции на сумму более 100000 рублей, обогащай данные информацией о клиенте из PostgreSQL-таблицы public.clients по полю client_id, результат публикуй в Kafka-топик high_value_transactions и параллельно сохраняй в S3 бакет compliance-archive с партиционированием по дате.
